# 家庭实验室真实设备概览

本仓库记录了我的家庭网络与虚拟化实验环境，涵盖硬件设备、拓扑结构及学习规划。所有配置均用于网络技术、系统运维和安全攻防的实践与验证。

---

## 一、软路由 / 路由设备

**设备型号**：FriendlyElec NanoPi R4S（R4S）

**运行系统**：OpenWrt + OpenClash

**部署角色**：家庭网络出口网关或旁路由

**网络拓扑（当前）**：

```text
公网
  |
运营商
  |
R4S (OpenWrt / OpenClash)
  |
交换机
  |
PC / NAS / FNOS
```

---

## 二、二层交换机

**设备类型**：实体交换机（品牌/型号略，支持企业级功能）

**学习目标**：

- MAC 地址表学习与老化
- VLAN 划分与隔离
- Trunk 链路聚合
- STP / RSTP 生成树协议
- 二层安全攻击与防御（如 MAC 泛洪、DHCP Snooping）

**实验拓扑示例**：

```text
        Trunk
LSW7 ========== LSW8
 |              |
PC1            PC2
```

**端口分配**：

- PC1 → GE0/0/1
- PC2 → GE0/0/3

**扩展能力**：可接入多台交换机和多个 PC 节点，并可通过 CLOUD 云节点连接外部仿真环境，模拟企业二层网络。

## 三、NAS / 服务器设备

**系统**：FNOS（轻量级 NAS 操作系统）

**主要用途**：

- Docker 容器服务
- Minecraft 游戏服务器
- Web 服务（Nginx / Apache）
- 虚拟化运行环境

**虚拟化资源分配**：

| 虚拟机   | 角色                 | CPU  | 内存    |
|----------|----------------------|------|---------|
| WRT1     | OpenWrt 旁路由       | 1 核 | 1 GB    |
| WRT2     | 备用 OpenWrt 实例    | 1 核 | 1 GB    |
| Kali     | 渗透测试 / 安全实验  | 2 核 | 2 GB    |

**FNOS 内部结构**：

```text
FNOS
 |
 +-- WRT1 (OpenWrt 旁路由)
 +-- WRT2 (备用)
 +-- Kali Linux
```

## 六、未来学习规划：企业网络设备模型

**目标拓扑**：

```text
Internet
    |
边界防火墙
    |
核心三层交换机
    |
接入交换机
    |
终端设备
```

**各设备学习重点**：

| 设备类型           | 学习内容                                                      |
|--------------------|---------------------------------------------------------------|
| 路由器             | 路由表转发、静态/动态路由、NAT、VPN、OSPF                    |
| 二层接入交换机     | MAC 地址表、VLAN 划分与隔离、Trunk、STP/RSTP                 |
| 三层交换机         | 跨 VLAN 路由（SVI）、ACL、DHCP 中继                          |
| 边界防火墙         | 安全策略、状态检测、入侵防御、应用识别                       |
| 无线 AP            | 802.11 标准、无线安全认证（WPA2/3）、漫游                    |
| IDS/IPS            | 流量深度检测、异常行为告警、规则编写                         |
| 管理设备           | SSH 安全登录、SNMP 监控、Telnet（实验用）                    |
